# math-notes

Expository notes, written in LaTeX. Each folder has the source and a compiled PDF.

- **[Quaternions and Octonions, from the Coordinate Plane](quaternions/quaternions.pdf)**: starting from the coordinate plane, through the complex numbers, to quaternions and octonions. This is the math behind [octonion_fractals](https://github.com/g8r-b8/octonion_fractals).
- **[The Monster Group](monster/monster.pdf)**: what sporadic simple groups are, and a timeline of all 26 in order of discovery, ending at the largest.
- **[The Strong Chromatic Index and the Erdős–Nešetřil Conjecture](strong_chromatic/strong_chromatic.pdf)**: from graph basics through a proof of Vizing's theorem to strong edge colouring and the conjecture.

See also [Erdős Lab](https://g8r-b8.github.io/erdos-lab).
